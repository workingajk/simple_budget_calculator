# Simple Budget Calculator

A small budgeting interface project with pages for registration and login, implemented with HTML and JavaScript.

## Tech Stack
- HTML5
- JavaScript

## Run Locally
Open `index.html` in a modern browser. No build step is required for the static frontend.

## Project Structure
- `index.html` — main budget interface
- `login.html` — login page
- `register.html` — registration page
- `script.js` — client-side behavior
- `task.md` — task details

This project is for learning and demonstration; do not enter sensitive financial information.
